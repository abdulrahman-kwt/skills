# قطع المحرك وشلون تنستخدم

كل فيلم ملف HTML واحد، مقاسه 1080×1920، وفيه دالة `window.renderAt(t)` ترسم الثانية `t`. ابدأ دايماً من نسخة `template/film.html`.

## الهيكل
```js
import { createGlobe, seg, es, ease, lerp, cl, spring } from './engine/globe.js';
import { createStage, label, pin, route, captions, counter, timeline, addCanvas, shape } from './engine/overlay.js';
import { createBlock } from './engine/block.js';            // بس إذا تحتاج القطعة المقصوصة

const DUR = 30; window.DUR = DUR;                           // طول الفيلم بالثواني
const S = createStage();
const G = await createGlobe({ canvas: S.canvas });
// ... تعريف القطع مرة وحدة هني ...
window.renderAt = function (t) { /* حدّث كل قطعة حسب t */ };
await document.fonts.ready; window.renderAt(0); window.READY = true;
```
القطع تنعرّف **مرة وحدة برا** `renderAt`، وداخلها بس تنادي `update` أو `set`. لا تسوي عناصر يديدة داخل `renderAt`.

## أدوات التوقيت
- `seg(t, a, b)`: يطلع 0 قبل الثانية a، و1 بعد b، ويمشي بينهم. هذا أساس كل حركة.
- ظهور واختفاء: `seg(t, 4, 4.4) * (1 - seg(t, 8, 8.4))`.
- `es(x)`: نعومة بالبداية والنهاية. `ease(x)`: أقوى (حق حركة الكاميرا الطويلة والزمن).
- `spring(x)`: نطة فيها ارتداد (حق الدبابيس والعناوين).
- `lerp(a, b, x)`: قيمة بين a و b. `cl(x)`: يحصر بين 0 و1.

## الكورة: `G`
| الأمر | شنو يسوي |
|---|---|
| `G.view({ lon, lat, dist, y })` | الكاميرا. المكان `(lon, lat)` يصير بنص الشاشة. `dist`: 10 = الكورة كاملة، 6 إلى 8 = نص الكورة، 4 إلى 5 = قارة، 2.6 إلى 3.2 = منطقة (كم دولة)، 2.2 = أقرب شي (أقل من جذي السواحل تبين خشنة). `y`: ينزّل الكورة (سالب) أو يرفعها؛ `-0.2` يخلي مكان للعداد فوق. |
| `G.age(a)` | السواحل قبل `a` مليون سنة (0 = اليوم، لين 200). |
| `G.tint({ polys, rings, amount })` | يلون أرض بلون التمييز. `polys`: أرقام قطع من `polyAt`. `rings`: أشكال حرة `[[lon,lat],...]` (بس اليابسة اللي داخلها تتلون). `amount` من 0 لين 1. |
| `G.ridge(points, amount, far)` | سلسلة جبال بثلج على خط نقاط (4 إلى 9 نقاط). `amount` ينمّيها. `far`: 1 لما الكاميرا بعيدة، 0 لما قريبة. |
| `G.glow(amount)` | يضوي الماي حوالين السواحل. نبضة تقول «في شي يصير هني». |
| `G.terrain(amount)` | التضاريس الحقيقية على اليابسة (جبال، صحاري، خضار). شغالة بالعادة (1). `0` يرجع الأرض لون واحد، وهذا أنسب إذا تبي تلون قطع بـ`tint` وتبيها تبين قوية. تنطفي بروحها إذا `age` أكبر من 0. |
| `G.render()` | يرسم. **لازم بعد `view` وقبل أي `project` أو `update`.** |
| `G.distFor(degrees)` | يحسب لك `dist` اللي يدخّل هالعدد من الدرجات داخل العرض الآمن. مثلاً طريق من خط طول 30 لين 110 على خط عرض 38: `G.distFor(80 * 0.8)`، وهو يخلي مكان للأسماء عند الطرفين (درجات الطول تصغر كل ما بعدت عن خط الاستواء، فاضربها بـ0.8 حوالين خط 38، و0.65 حوالين خط 50). **استخدمه بدال التخمين.** |
| `G.project(lon, lat, h)` | مكان النقطة على الشاشة: `{ x, y, visible }`. `visible` يصير false إذا ورا الكورة. |
| `G.polyAt(lon, lat)` | رقم قطعة الأرض اللي فيها هالنقطة (-1 إذا بحر). |
| `G.centroid(poly, age)` | نص القطعة بعمر معين: عشان اسم يلحق قارة وهي تمشي. |

**انتبه لـ`polyAt`:** القطع مقصوصة حسب الصفائح، مو حسب الدول ولا القارات. الهند قطعة بروحها، وأستراليا، وأفريقيا تقريباً، بس آسيا وأوروبا قطعة وحدة كبيرة ومعاها قطع صغار. **جرب دايماً بلقطة قبل لا تعتمد.** وإذا تبي منطقة محددة، ارسمها بـ`rings`.

ألوان الكورة تتغير من `createGlobe({ canvas, deep, shallow, coast, inland, tint, atmo, bg, shine, terrain })` (`shine`: لمعة الشمس على البحر، 0.3 بالعادة، و0 إذا طلعت بقعة بيضا تسحب العين) (كل لون `[r,g,b]` من 0 لين 1، و`bg` لون نصي). وألوان الكتابة من المتغيرات بأول `engine/style.css`.

## فوق الكورة
| القطعة | الاستخدام |
|---|---|
| `label(S, 'نص', { size, kind })` | نص حر. `kind: 'title'` للعناوين. بعدها `.set(x, y, opacity, scale)` (x و y نص النص). |
| `pin(S, G, lon, lat, 'اسم', { side, size, dx, dy, dot })` | نقطة على مكان واسمه جنبها. `side`: `top` أو `bottom` أو `left` أو `right`، و`dx` و`dy` يزحزحون الاسم بالبكسل. `dot: false` اسم بدون نقطة (صحرا، بحر، جبال). `.update` يرجّع مكانه على الشاشة `{ x, y, visible }`. بعدها `.update(opacity, pop)`. ينخش كله (النقطة والاسم) إذا المكان ورا الكورة أو برا اللي يبين بالآيفون، فإذا دبوس ما طلع، الكاميرا هي اللي لازم تتعدل. |
| `route(S, G, [[lon,lat], ...], { lift, color, width, smooth })` | طريق ينرسم على انحناء الكورة ويعدي المحطات بالترتيب. `lift`: ارتفاع القوس (0 = لازق بالأرض حق طرق البر والبحر، 0.08 حق الطيران). `smooth`: يدوّر الزوايا عند المحطات (شغال بالعادة). بعدها `.update(progress, opacity)`، والتقدم محسوب بالمسافة فراس الطريق يمشي بسرعة ثابتة. ومعاه: `.stops[i]` (التقدم اللي يوصل فيه المحطة i) و`.at(progress)` (مكان راس الطريق `[lon, lat]`). |
| `captions(S, [[بداية, نهاية, 'نص <b>مميز</b>'], ...], { top, shade })` | الكابشن. سطر واحد بكل مرة، ويصغر بروحه إذا طويل. `.update(t)`. `shade: true` يحط ظل غامق ناعم ورا السطر (يطلع ويختفي مع الكابشن): **شغّله إذا الكاميرا تقرّب** وصار تحت الكتابة أرض فاتحة أو بحر. |
| `counter(S, { digits, pre, post, done, top })` | عداد أرقام يلف (`digits` من 1 لين 5 خانات). `pre` و`post` سطر فوقه وتحته. `done`: كلمة تبدل الرقم لما يوصل النهاية. `.set(value, { opacity, doneAt, bump })`. |
| `timeline(S, { min, max, from, ticks, top })` | شريط زمن ونقطة تمشي. `.set(value, opacity)`. |
| `shape(S, 'rect' أو 'path' ..., { خصائص SVG })` | أي شكل خام (مستطيل تحديد، سهم). |

## وصفة: طريق بمحطات والكاميرا تلحقه
```js
const STOPS = [[108.9, 34.3], [75.99, 39.47], [66.97, 39.65], [44.4, 33.3]];
const road = route(S, G, STOPS);                                  // lift 0 = طريق بر
const pins = ['شيآن', 'كاشغر', 'سمرقند', 'بغداد'].map((n, i) => pin(S, G, ...STOPS[i], n));
// داخل renderAt:
const go = seg(t, 6, 15);                                         // الطريق ينرسم من الثانية 6 لين 15
const head = road.at(go);                                         // وين راسه الحين
G.view({ lon: head[0], lat: head[1] - 3, dist: 3 }); G.render();        // lat أقل من الراس = الراس يطلع فوق النص شوي
road.update(go);
pins.forEach((p, i) => { const a = (go - road.stops[i]) * 9; p.update(go >= road.stops[i] ? 1 : 0, spring(cl(a / 0.5))); });   // 9 = طول الرسم بالثواني
```
- طريق بمحطات ياخذ بالمتوسط ثانية ونص إلى ثانيتين **لكل محطة**. بس المحطات ما توصل بفواصل متساوية، لأن التقدم بالمسافة. **عشان توقّت الكابشن على وصول كل محطة:** اطبع الأوقات مرة وحدة بعد تعريف الطريق: `console.log(road.stops.map(s => (6 + s * 9).toFixed(2)))` (6 = بداية الرسم، 9 = مدته)، وشغّل `--stills` وبتطلع لك بسطر يبدأ بـ`film:`. وبعدها اكتب الكابشن على هالأوقات.
- **أسماء وايد قريبة من بعض:** خل اسمين بس ظاهرين: اسم المحطة اللي وصلها الطريق واللي قبلها، والأقدم يختفي. وبدّل `side` بينهم (فوق، تحت)، وإذا ما كفى استخدم `dx` و`dy`.
- **سمِّ اللي يذكره الكلام:** إذا الكابشن يقول «صحرا تكلامكان» أو «جبال»، حط اسمها على مكانها: `pin(S, G, lon, lat, 'تكلامكان', { dot: false, size: 44, color: '#E9D9A8' })`.
- **إذا ما لقيت مصدر لآخر محطة،** وقف الطريق عند آخر محطة لها مصدر، وخل الكلام يقول نفس الشي. لا تقول «لين البحر» والخط واقف بالبر.
- بعد ما يخلص، بعّد الكاميرا عشان يبين كله: `dist: G.distFor(عرضه بالدرجات)`.
- الخط بين محطتين تقريبي، مو المسار الحقيقي على الأرض. كل ما زادت المحطات (من مصدر) صار أصدق.
- فروع: طريق ثاني بلون ثاني (`color: '#F2B25C'`) وعرض 6.

## القطعة المقصوصة: `createBlock`
```js
const c2 = addCanvas(S), B = createBlock({ canvas: c2 });
B.squeeze(q);                       // 0 = مسطحة، 1 = الطبقات انثنت والجبل طلع
B.view({ az, el, dist, ty });       // az = -Math.PI/2 و el قريب من Math.PI/2 = من فوق مثل الخريطة
B.render(); c2.style.opacity = 1;
B.project(x, y, z)                  // مكان نقطة من القطعة على الشاشة، حق الأسماء
```
تنفع لأي شي تحت الأرض: جبل، بركان، زلزال، طبقات. طريقة «القص من الخريطة» كاملة (مستطيل ينرسم، والقطعة تطلع من مكانه وترجع) موجودة بـ`examples/tectonics.html`، انسخها من هناك. ألوان الطبقات من `createBlock({ layers })`.

## قواعد الشكل
- **الحدود الآمنة:** x من 131 لين 949، و y من 150 لين 1620. الكورة عادي تطلع برا، بس الكتابة والدبابيس والمكان المهم لا.
- **أماكن ثابتة:** العداد فوق (`top: 226`)، وشريط الزمن تحته (`top: 592`)، والكابشن تحت (`top: 1524`). لا تحط اسم فوق الكابشن أو العداد.
- **العداد والكورة ما يتلاقون:** العداد ياخذ من فوق لين y = 520 (ومع شريط الزمن لين 660). الكورة لازم تكون تحته: `dist` حوالين 9 أو أكثر مع `y` من `-0.2` لين `-0.36`، وتأكد باللقطة إن راس الكورة تحت الكتابة. لا تطلّع العداد والكاميرا قريبة.
- **لا تكرر نفس الرقم مرتين:** إذا العداد يعرض الرقم، الكابشن يقول شنو هالرقم، مو يعيده.
- **أصغر خط 44.** اسم المكان 46 إلى 62، والعنوان 72 إلى 96، والكابشن 58.
- **كلمات الكابشن:** 3 إلى 5 كلمات بالسطر، وكلمة وحدة مميزة بـ`<b>`.
- **اسمين بنفس الوقت بالكثير** حوالين الكورة، وبعيد عن بعض. غيّر `side` إذا تداخلوا.
- **لما الكاميرا قريبة،** خل المكان المهم بنص الشاشة أو فوق النص شوي، مو تحت (تحت مكان الكابشن).

## قواعد الحركة
- **أول ثانيتين فيهم الموضوع:** المكان اللي تبدأ منه القصة يكون قدام الكاميرا ومعلّم (دبوس أو لون) من أول لقطة. لا تبدأ بكورة تلف وعنوان بس.
- **آخر ثانيتين فيهم حركة:** لا تخلي الفيلم يوقف على صورة ثابتة. خل الكاميرا تبتعد شوي أو الكورة تلف.
- **استغل التضاريس:** إذا القصة تمر على جبال أو صحرا أو بحر، قرّب الكاميرا عليها وخل الكلام يذكرها. هي حقيقية، فالمشاهد يشوف ليش الطريق لف من هني.
- **لقطة وحدة متصلة:** الكاميرا تمشي من مكان لمكان وما تقطع. حركة الكاميرا بين مكانين 1.5 إلى 2 ثانية بـ`es` أو `ease`.
- **الكورة ما توقف:** خل فيها دوران خفيف دايماً (`lon` يزيد 0.5 إلى 2 درجة بالثانية) حتى والكاميرا ثابتة.
- **الدبوس ينط** بـ`spring` خلال نص ثانية، والاسم يطلع معاه.
- **الطريق ينرسم** خلال 1.5 إلى 2.5 ثانية، ويبدأ مع الكلمة اللي تذكره.
- **الطريق لما يكون `smooth`** يدوّر الزوايا. إذا شفت باللقطة لفة غريبة عند محطة، زد محطة بينهم أو خله `smooth: false`.
- **الظهور 0.3 إلى 0.4 ثانية،** والاختفاء أسرع (0.25).
- **الزمن** (`G.age`) يتحرك بـ`ease` على 8 ثواني أو أكثر، عشان العين تلحق القارات.
- **كل شي على الكلام:** الشي يطلع مع الكلمة اللي تذكره، مو قبلها بثانية ولا بعدها.

## غلطات شائعة
- نسيت `G.render()` قبل `pin.update` أو `project`: الأماكن تطلع من الفريم اللي قبل.
- حطيت `[lat, lon]` بدال `[lon, lat]`: الدبوس يروح مكان ثاني. الكويت `[47.98, 29.37]`.
- مسار يعدي خط التاريخ (180) بشكل طويل: قسمه نقطتين.
- عنصر انسوى داخل `renderAt`: الرندر يبطئ والعناصر تتكرر.
