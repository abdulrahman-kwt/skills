# cartoon-me: سوّ شخصيتك الكرتونية بصوتك

أداة تمشي معاك خطوة خطوة، من صورك لين شخصية كرتونية ثلاثية الأبعاد تشبهك وتتكلم بصوتك الحقيقي.
نفس الطريقة اللي سويت فيها شخصيتي، وبنفس البرومتات.
عبدالرحمن، @abdulrahman.kwt

## شنو تسوي
1. **الصور:** تعطيها 3 لين 5 صور لك.
2. **الأشكال:** تسألك أول: تبي ويهك الحقيقي يبين ولا لا؟ إذا لا، تطلّع لك نسخ كرتونية بس. وإذا إي، تطلّع 3 أشكال (كرتوني، ومجسم ناعم، وشبه واقعي)، وأنت تختار.
3. **ضبط الجسم:** نسخ مرقمة جنب بعض، لين تقول «هذا».
4. **التثبيت:** ورقة 6 تعابير، وورقة 6 وقفات، وصورة على خلفية خضرا.
5. **الكلام:** الشخصية تتكلم بتسجيلك (Wan 2.7)، وتصليح الشفايف (Sync)، و4K.

وقبل كل خطوة تقولك كم بتكلف، وتنطر موافقتك.

## جهّز قبل لا تبدا
- **اشتراك Higgsfield مدفوع، ورصيد يكفي:** الرحلة كاملة تقريباً 100 رصيد، ونسخة التجربة تقريباً 50.
- **3 لين 5 صور لك:** من قدام، ومن جنب، وقريبة، وكامل الجسم. **باللبس اللي تبي الشخصية تلبسه.**
- **تسجيل بصوتك** بمكان هادي. كل قطعة 15 ثانية بالكثير، ولأول تجربة 5 ثواني تكفي.
- **وحدة من هذي:** Claude Code، أو Codex، أو تطبيق Claude.
- **برنامج ffmpeg** (مجاني): للمقارنة بين الصور، وقص الصوت، وشيل الخلفية الخضرا. إذا مو عندك، الأداة تعرض عليك تركّبه، وتمشي بدونه إذا ما تبي.
- **لـCodex بس:** Node.js من nodejs.org.

## التنصيب

### الطريقة السهلة (Claude Code أو Codex)
افتح Claude Code أو Codex، واكتب له:
> ركّب لي سكل cartoon-me من https://github.com/abdulrahman-kwt/skills بمكان السكلات حقك، واربطني بـHiggsfield.

هو ينزّل الأداة ويحطها بمكانها ويقولك شنو باقي. **اللي تسويه أنت بإيدك:** تسجيل الدخول بحساب Higgsfield لما يفتح المتصفح، وممكن يطلب منك تكتب أمر واحد أو تكتب `/mcp` وتختار higgsfield.

وبعدها سكّر البرنامج وافتحه مرة ثانية، واكتب: «سو لي شخصيتي».

**مجربة على Claude Code.** والمفروض تشتغل على Codex بنفس الطريقة، وإذا واجهتك مشكلة قول لي على انستقرام.

### بإيدك
نزّل المستودع كملف مضغوط (زر Code الأخضر، وبعده Download ZIP)، وافتحه. بتلقى فيه مجلد `cartoon-me`.

**Claude Code:**
1. بالـFinder، اضغط Cmd+Shift+G واكتب `~/.claude/skills`. إذا ما لقى المجلد، سوّ مجلد اسمه `skills` داخل `~/.claude`.
2. انسخ مجلد `cartoon-me` كامل داخله.
3. اربط Higgsfield بأمر واحد **بالـTerminal** (مو بالشات):
   ```bash
   claude mcp add --transport http higgsfield https://mcp.higgsfield.ai/mcp
   ```
   وبعدها داخل Claude Code اكتب `/mcp`، واختار higgsfield، وسجّل دخول.
4. اكتب: «سو لي شخصيتي».

**Codex:**
1. بالـFinder، اضغط Cmd+Shift+G واكتب `~/.agents/skills`. إذا ما لقى المجلد، سوّه.
2. انسخ مجلد `cartoon-me` كامل داخله، وسكّر Codex وافتحه.
3. اربط Higgsfield **بالـTerminal**. تحتاج Node.js من nodejs.org أول:
   ```bash
   npm i -g @higgsfield/cli
   higgsfield auth login
   ```
4. اكتب `$cartoon-me`، أو «سو لي شخصيتي».

الخطوات مكتوبة بشكل عام. إذا جهازك أو نظامك غير، قول للبرنامج وهو يضبط المسار والأمر على جهازك.

### تطبيق Claude (بدون Terminal)
1. **اربط Higgsfield:** Settings → Connectors → Add custom connector، والرابط `https://mcp.higgsfield.ai/mcp`، وسجّل دخول بحساب Higgsfield.
2. **ارفع الأداة:** اضغط مجلد `cartoon-me` بروحه كملف zip، وارفعه من قسم Skills بالإعدادات، وتأكد إن Code execution شغّال.
3. اكتب: «سو لي شخصيتي»، واسحب صورك للشات لما يطلبها.

### كبرومت (أي شات)
افتح `SKILL.md` وانسخه كله، والصقه بأول رسالة، وبعده الصق الملفين اللي داخل `references/`. الأفضل يكون الشات مربوط بـHiggsfield. وإذا مو مربوط، بيعطيك البرومتات تلصقها بموقع higgsfield.ai بنفسك.

## وين أحط صوري؟
- **Claude Code أو Codex:** حطها بالمجلد اللي فاتح فيه البرنامج، أو اسحبها للشات.
- **تطبيق Claude:** اسحبها للشات.

## خصوصيتك
- صورك وصوتك يترفعون لـHiggsfield عشان التوليد، والأداة تطلب إذنك قبل أول رفع.
- سوّ شخصيتك أنت بس، أو شخصية واحد موافق.

## الملفات
- `SKILL.md`: الخطوات اللي يمشي عليها Claude أو Codex.
- `references/prompts.md`: البرومتات بالإنجليزي لكل خطوة.
- `references/higgsfield.md`: شلون يوصل Higgsfield، والكلفة، وأوامر الصوت وشيل الخلفية الخضرا.

ما فيها سكربتات، كلها نص تقدر تقراه. والأداة تشغّل أوامر بجهازك بس بعد ما تقولك: تركيب Higgsfield، وتنزيل الصور والمقاطع لمجلد الشغل، وffmpeg للصوت والمقارنة وشيل الأخضر.
