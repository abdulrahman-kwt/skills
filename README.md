# أدوات عبدالرحمن

أنا عبدالرحمن، وكل شي أتعلمه بالـAI، أعلمك إياه.
هني أحط الأدوات اللي أسويها وأشرحها بفيديواتي: [@abdulrahman.kwt](https://www.instagram.com/abdulrahman.kwt)

كلها **سكلات** (Agent Skills): ملفات نصية تعلّم Claude Code أو Codex شغلة معينة، ويمشي معاك فيها خطوة خطوة. مجانية، وتقدر تقراها قبل لا تستخدمها.

## الأدوات

| الأداة | شنو تسوي | تحتاج |
|---|---|---|
| [cartoon-me](cartoon-me/) | تحوّل صورك لشخصية كرتونية ثلاثية الأبعاد تشبهك وتتكلم بصوتك | اشتراك Higgsfield مدفوع |
| [globe-motion](globe-motion/) | تسوي لك فيديو موشن على كورة أرضية ثلاثية الأبعاد عن أي قصة تصير على الخريطة، من فكرة لين ملف فيديو | Node.js (مجاني) |

## شلون تركّب أي أداة
افتح Claude Code أو Codex، واكتب له:

> ركّب لي سكل cartoon-me من https://github.com/abdulrahman-kwt/skills

وغيّر اسم الأداة حسب اللي تبيها. وتفاصيل كل أداة داخل مجلدها.

## ملاحظات
- الأدوات تشتغل على جهازك، وما تدز لي أي شي من ملفاتك.
- بعض الأدوات تستخدم خدمات مدفوعة من شركات ثانية (مكتوب جنب كل أداة). أنا ما آخذ منها شي.
- لقيت مشكلة أو عندك اقتراح؟ افتح Issue هني، أو كلمني على انستقرام.
